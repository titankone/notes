Registre d’appel mensuel

Choisis la classe et le mois. Une case vide signifie présent. Codes d’absence : + = absent toute la journée (2 demi-journées), - = absent le matin (1 demi-journée), | = absent l’après-midi (1 demi-journée). Coche « Férié » sur une date pour l’exclure des calculs. Les données sont enregistrées sur cet appareil.

Sauvegarder ou restaurer

🔒 SÉCURITÉ DU COMPTE — RÉINITIALISATION

Tu peux effacer les données scolaires du compte actuellement connecté sans supprimer les autres comptes NotesCI enregistrés sur cet appareil.

Attention : cette action est irréversible. Télécharge une sauvegarde avant de continuer si tu veux conserver tes données.

La sauvegarde contient les élèves et les notes de cette application. Elle est enregistrée dans un fichier que tu peux transférer entre ton téléphone et ton ordinateur.

Conseil : après chaque saisie importante, télécharge une sauvegarde et garde une copie dans un endroit sûr. Le fichier de sauvegarde n'est pas chiffré : ne le partage pas publiquement.
